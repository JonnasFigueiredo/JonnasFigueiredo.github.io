Sobre

Jonnas Figueiredo, engenheiro de automação de testes

Sou engenheiro de automação de testes (QA/SDET). Meu maior domínio é em Java e Selenium, mas o que me move mesmo é entender o negócio por trás do sistema. No fim, é isso que faz um teste valer alguma coisa.

Trabalho com testes de aplicações web, mobile, API e backend. Além de Java e Selenium, mexo bastante com Appium, Playwright e TypeScript, montando e mantendo a automação que dá segurança para entregar sem regressão.

Qualidade em sistemas de IA

Nos últimos tempos venho levando esse mesmo rigor para sistemas de inteligência artificial. Um modelo de linguagem é não-determinístico: a mesma pergunta pode gerar respostas diferentes a cada chamada. Isso quebra a premissa básica de qualquer suíte de testes, e resolver esse problema virou o fio condutor de boa parte do que eu construo.

Compartilhar o que aprendo

Faço palestras sobre qualidade e automação de testes e mantenho um canal noYouTube. Meusprojetos open source ficam noGitHub.
