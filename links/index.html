  • Extensão para Chrome

    Proteu QA

    Gere dados de teste, preencha formulários e prepare a automação na própria página que está testando. No modo Mapear, você clica nos campos e botões da tela, e o Proteu transforma cada elemento em uma variável com seu seletor.

    • Confira os seletores antes de automatizar: o painel mostra quantos elementos cada opção encontra na página. Exporte o mapeamento para Selenium, Playwright, Cypress ou Robot Framework.
    • Recrie os mesmos dados: cada pessoa fictícia tem uma referência copiável. Guarde essa referência no relato de um problema para repetir o teste com os mesmos dados.
    • Prepare casos variados: perfis de 12 países, exportação em lote e textos com tamanho exato, contando caracteres ou bytes conforme o teste exige.
    • Use o painel lateral para manter a ferramenta aberta enquanto interage com a página. A geração e o mapeamento funcionam localmente, sem enviar os dados a um servidor.
    Conhecer na Chrome Web Store ↗Ver o código ↗

  • Requisitos e testes com apoio de IA

    Hefesto

    Reúne a escrita de histórias, a revisão de requisitos e a preparação dos testes em um fluxo integrado ao Jira. Você começa com um requisito em texto ou uma imagem da tela e revisa a história e os critérios de aceite sugeridos pela IA.

    • Revise a história com os critérios INVEST para identificar lacunas, riscos e informações que ainda faltam.
    • Gere casos de teste como subtarefas no Jira e cruze os testes com os critérios de aceite para enxergar o que ainda não foi coberto.
    • Registre a execução, anexe evidências e gere relatórios. Use a interface web ou acesse as funções por um assistente compatível com MCP.

  • Automação de testes mobile

    Hermes

    Framework com Appium, Java e Cucumber para testar aplicativos Android e iOS. Os cenários são escritos em português e compartilham passos e objetos de tela; as diferenças entre as plataformas ficam concentradas nos seletores e nas ações específicas.

    • Acompanhe exemplos de login, catálogo, carrinho e compra completa, com cenários que descrevem o comportamento esperado do aplicativo.
    • Execute cada cenário a partir de um estado conhecido, com limpeza do aplicativo, gestos nativos e esperas explícitas.
    • Consulte execuções no GitHub Actions e relatórios Allure com capturas de tela nas falhas. O projeto inclui a suíte Android e testes essenciais no simulador iOS.
