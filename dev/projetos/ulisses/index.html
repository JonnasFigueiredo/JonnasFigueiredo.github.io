Ulisses

Cadastro e comparação facial com inferência no backend.

Tipo
Aplicações full stack
Estado
Em validação
Tecnologias
Java 21 · Spring Boot · React · ONNX Runtime · Docker

Aplicação experimental de biometria facial com autenticação, captura guiada por câmera, histórico de verificações e uma demonstração de registro de entrada e saída.

Ver código no GitHub ↗Conversar sobre o projeto ↗

O problema

Integrar captura de vídeo, verificação de identidade e proteção de dados em uma experiência que possa ser testada de ponta a ponta.

A solução

O frontend React guia cadastro e verificação. O backend Java autentica usuários e executa detecção, alinhamento e comparação facial com modelos ONNX, além de registrar o histórico.

Decisões técnicas

01

Inferência no backend

O processamento dos modelos fica concentrado no serviço Java, permitindo controlar versões, regras e validação das entradas.

02

Segredos de produção explícitos

O perfil de produção exige configuração dos segredos de autenticação e criptografia dos templates.

03

Fluxo demonstrável

Cadastro, verificação e histórico formam um percurso completo, com builds Docker e testes automatizados das regras principais.

Estado e próximos passos

A eficácia biométrica ainda precisa de testes com dados reais. O projeto não é uma solução antifraude certificada nem um sistema de ponto homologado.
