Aplicações full stack / Open source

Hefesto

Requisitos, histórias e testes conectados ao Jira em um fluxo só.

Tipo
Aplicações full stack
Estado
Open source
Tecnologias
Java 17 · Spring Boot · React · TypeScript · Jira · MCP

Plataforma web para apoiar QA e Product Owners: transforma requisitos em histórias, casos de teste e análise de cobertura. A mesma lógica também é exposta a assistentes por um servidor MCP.

Ver código no GitHub ↗Conversar sobre o projeto ↗

O problema

Escrever histórias, revisar critérios, gerar testes e acompanhar cobertura costuma espalhar o contexto entre várias ferramentas. O objetivo foi reunir essas etapas sem perder a rastreabilidade no Jira.

A solução

Uma interface React organiza o trabalho de ponta a ponta. O backend Spring Boot integra Jira e provedores de IA, registra execuções e oferece as mesmas operações por ferramentas MCP.

Decisões técnicas

01

Jira como fonte das histórias

A plataforma lê e atualiza issues e subtarefas, mantendo o vínculo entre critérios de aceite, testes e evidências.

02

Uma lógica, duas interfaces

Os fluxos podem ser acionados pela web ou por clientes MCP, sem duplicar a lógica de negócio.

03

Provedor de IA substituível

O projeto permite escolher modelos por tarefa, inclusive uma opção local, em vez de prender o fluxo a um único serviço.

Estado e próximos passos

Para experimentar as integrações completas, é preciso configurar credenciais do Jira e do provedor de IA escolhido.
