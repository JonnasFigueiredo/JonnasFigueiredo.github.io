Castalia

Busca em documentação técnica com origem verificável.

Tipo
Backend e sistemas
Estado
Open source
Tecnologias
Java 21 · PostgreSQL · pgvector · MCP · Docker

Serviço Java que indexa documentação e entrega trechos relevantes, com fonte, a agentes de IA por MCP. Ajuda a escrever cenários de teste ancorados nas regras documentadas.

Ver código no GitHub ↗Conversar sobre o projeto ↗

O problema

Em sistemas grandes, regras ficam espalhadas por documentos. Um agente pode produzir um cenário plausível, mas incorreto, quando não encontra a fonte certa.

A solução

Um pipeline transforma documentos em trechos indexados com embeddings. O servidor MCP responde a consultas com os trechos relevantes e seus links de origem.

Decisões técnicas

01

Fonte em cada resultado

O caminho de títulos e o link do documento acompanham o trecho para que a regra possa ser conferida.

02

Lacuna como resposta válida

Uma busca sem correspondência retorna vazia, sinalizando ausência de documentação em vez de inventar comportamento.

03

Embeddings configuráveis

A ingestão aceita provedores na nuvem ou modelos locais, conforme a infraestrutura disponível.

Estado e próximos passos

O Castalia é um serviço de busca e integração MCP; não há interface web para usuários finais.
