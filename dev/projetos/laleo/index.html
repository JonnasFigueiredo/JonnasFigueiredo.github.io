Laleo

Exercícios de fala que unem produto, voz e interface infantil.

Tipo
Aplicações full stack

MVP funcional
Tecnologias
Java 17 · Spring Boot · React · TypeScript · PostgreSQL

Aplicação web de apoio ao desenvolvimento da fala infantil, com exercícios, avatar 3D, acompanhamento de progresso e recursos de voz. Um produto que conecta experiência de uso, API Java e serviços de fala.

Ver código no GitHub ↗Conversar sobre o projeto ↗

O problema

Criar uma experiência acessível para praticar sons da fala em português, sem transformar a atividade em uma sequência de formulários. A criança precisa entender o exercício e receber uma resposta clara a cada interação.

A solução

O frontend em React conduz as atividades e apresenta um avatar 3D. A API em Spring Boot mantém perfis, exercícios e progresso; um serviço separado processa a transcrição de áudio quando está disponível.

Decisões técnicas

01

Separar as responsabilidades

A interface cuida da interação e da captura de áudio; a API concentra regras e progresso; a transcrição fica em um serviço próprio.

02

Deixar o estado da experiência explícito

Perfis por criança, estrelas e álbum permitem acompanhar o percurso sem misturar o progresso de usuários diferentes.

03

Tratar IA como recurso opcional

A conversa tem modo de demonstração. A chave do provedor permanece no servidor quando a integração real está configurada.

Estado e próximos passos

O conteúdo e a pontuação de pronúncia ainda precisam de validação clínica antes de uso terapêutico real.
