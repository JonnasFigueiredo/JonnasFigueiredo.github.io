O que eu construo

Quase tudo aqui nasceu de um problema real de qualidade que eu queria resolver direito. Os nomes vêm da mitologia grega — cada um diz algo sobre o que a ferramenta faz.

Qualidade de IA

Testar sistemas não-determinísticos com rigor de engenharia.

Aletheia

ἀλήθεια — "verdade", o que não está oculto

Framework Java para avaliar LLMs de forma determinística e agnóstica de provedor. Transforma "esse prompt melhorou ou piorou?" em um teste de CI com resposta objetiva.

  • Java 17
  • JUnit
  • GitHub Actions

Pythia

Πυθία — a sacerdotisa oracular de Delfos

Serviço RAG enxuto acompanhado da suíte PyTest que prova que ele funciona: métricas de retrieval, checagem de fidelidade, baseline de regressão de prompt e testes de segurança. Roda em CI sem custo de API.

  • Python 3.11
  • PyTest
  • RAG

Argos

Ἄργος Πανόπτης — o gigante de cem olhos, que tudo vigia

Validador de qualidade para projetos de automação Selenium, Cucumber e Java. Regras estruturais rodam sem consumir tokens; a análise semântica por LLM é opcional. Também exposto como servidor MCP.

  • Java
  • Selenium
  • MCP

Hefesto

Ἥφαιστος — o deus da forja

Plataforma de QA/PO assistida por IA, também exposta como servidor MCP. Recebe um requisito em texto ou print de tela e devolve história no Jira, casos de teste e relatório de cobertura.

  • IA
  • MCP
  • Jira

Castalia

Κασταλία — a fonte de água que inspirava os poetas

Motor de retrieval open source em Java para arquiteturas RAG agênticas. Indexa documentação técnica e a devolve, com a fonte, para agentes de IA via MCP. Não gera resposta: só recupera o trecho certo.

  • Java
  • MCP
  • RAG

  • Docker
