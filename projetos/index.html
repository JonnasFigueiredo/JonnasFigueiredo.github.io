Projetos

Projetos open source de automação de testes

Cada um destes projetos nasceu de um problema real de qualidade que eu quis resolver direito, e não de um exercício. Todos são públicos noGitHub e rodam em CI.

Automação de testes

Frameworks e ferramentas para testar aplicações web, mobile e API em CI.

Hermes

Ἑρμῆς, o mensageiro que atravessa todos os mundos

Framework de testes end-to-end mobile com Appium 2, Java 21 e JUnit 5. Screen Object Model, gestos nativos, reset determinístico de estado e emulador Android rodando dentro do GitHub Actions. Cenários em português, relatórios em Allure.

  • Java 21
  • Appium 2
  • JUnit 5
  • Allure

ShopGuard

Framework de testes end-to-end para e-commerce com Playwright e TypeScript. Cobre cross-browser, mobile, regressão visual, acessibilidade e API. Page Object Model por composição, fixtures próprias e login único por storageState, integrado a GitHub Actions e Allure.

  • TypeScript
  • Playwright
  • Allure

Proteu QA

Πρωτεύς, o deus que mudava de forma

Extensão de Chrome (Manifest V3) que gera massa de dados de teste, senhas e mapeamento de elementos sem sair da página que você está testando. Roda totalmente offline e não coleta nada.

  • JavaScript
  • Chrome MV3

Midas

Μίδας, o rei que transformava em ouro o que tocava

API de serviços financeiros (contas e transações) totalmente containerizada, construída para demonstrar uma stack moderna de Quality Engineering: Spring Boot e MySQL em Docker, testes de API e integração contra ambiente conteinerizado, validação de dados via SQL e CI no GitHub Actions.

  • Spring Boot
  • MySQL
  • Docker

Qualidade de sistemas de IA

Como testar software que não devolve a mesma resposta duas vezes.

Hefesto

Ἥφαιστος, o deus da forja

Plataforma de QA e Product Owner assistida por IA, também exposta como servidor MCP. Recebe um requisito em texto ou print de tela e devolve história no Jira, casos de teste e relatório de cobertura. Funciona por interface web ou por linguagem natural via MCP.

  • Java
  • IA
  • MCP
  • Jira

Aletheia

ἀλήθεια, "verdade", o que não está oculto

Framework Java determinístico e independente de provedor para testar qualidade de LLMs em CI. Baseline versionado, cliente mock sem custo de API e gate que quebra o build quando a qualidade regride.

  • Java 17
  • JUnit
  • GitHub Actions

Pythia

Πυθία, a sacerdotisa oracular de Delfos

Aplicação RAG acompanhada de uma suíte de qualidade de IA em PyTest: métricas de retrieval, checagem de fidelidade, baselines de regressão de prompt e testes de segurança. Determinística em CI e com custo zero de API.

  • Python 3.11
  • PyTest
  • RAG

Como eu escolho o que construir

A maior parte destas ferramentas resolve alguma versão do mesmo incômodo: automação de testes costuma parar no caminho feliz. Framework mobile que não reseta estado, suíte de e-commerce que só testa um navegador, requisito que vira caso de teste no braço, modelo de linguagem que ninguém sabe avaliar. Cada projeto ataca um desses pontos.
